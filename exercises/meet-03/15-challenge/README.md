# 15 · Challenge

# Tujuan

Menguji kemampuanmu menambah fitur baru ke Expense Tracker yang
sudah berjalan — persis seperti Mini Challenge di modul (Bagian 12):
"pilih satu, tidak ada jawaban salah, yang penting berani mencoba".

# Yang Dipelajari

Setiap challenge di sini memakai starter yang SUDAH LENGKAP (hasil
dari `11-complete-crud`) — kamu tidak mulai dari nol, tapi
MENAMBAHKAN satu fitur baru ke aplikasi yang sudah jalan. Ini lebih
dekat dengan pekerjaan nyata seorang developer: jarang sekali mulai
dari kertas kosong.

# File Yang Diubah

Kerjakan berurutan sesuai tingkat kesulitan:

| Level | Folder | Fitur | Konsep baru |
|---|---|---|---|
| Easy | [easy](easy) | Kategori Berwarna | CSS + Jinja `class` dinamis (tanpa SQL baru) |
| Medium | [medium](medium) | Filter Kategori | `request.args` + `SELECT ... WHERE` dinamis |
| Hard | [hard](hard) | Ringkasan Harian + Total | `SUM()` & `GROUP BY` (SQL agregasi) |

# Ekspektasi Hasil

Baca `README.md` di masing-masing folder untuk spesifikasi lengkap.
Setiap starter (`app.py`, `templates/`) sudah bisa langsung
dijalankan (`python app.py`) — kamu menambahkan fitur di atasnya,
bukan memulai dari file kosong.

# Hint

- Sudah mentok? Kunci jawaban ada di `16-solution` — tapi coba dulu
  sendiri minimal 15-20 menit.
- `easy` tidak butuh SQL baru sama sekali — murni CSS & Jinja. Kalau
  kamu berpikir butuh mengubah query, coba pikirkan ulang.
- `medium` dan `hard` memakai SQL yang HANYA disebut sebagai
  "petunjuk" di modul (`SUM()`, `WHERE` dinamis, `GROUP BY`) — wajar
  kalau perlu bereksperimen lebih lama.

# Checklist

yang sudah kamu bangun sendiri — bukti kamu bisa mengembangkan
aplikasi yang sudah ada, bukan cuma mengikuti tutorial dari nol.
