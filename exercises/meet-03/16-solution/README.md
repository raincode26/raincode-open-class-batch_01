# Tujuan

Menjadi referensi pembanding setelah kamu mengerjakan `15-challenge`
sendiri — bukan jalan pintas untuk menyalin sebelum mencoba.

# Yang Dipelajari

Membaca kode orang lain dan membandingkannya dengan pendekatanmu
sendiri sama pentingnya dengan menulis kode dari nol (lihat lagi
`12-read-source-code` dan `14-buggy`).

# File Yang Diubah

Tidak ada — folder ini read-only, untuk dibaca dan dibandingkan.

# Langkah Pengerjaan

1. Selesaikan dulu `15-challenge/easy`, `medium`, dan `hard`
   versimu sendiri.
2. Baru buka folder solusi yang sepadan di sini untuk membandingkan.
3. Kalau ada bagian solusi yang caranya beda dari punyamu tapi
   hasilnya sama — itu normal. Coding punya banyak jalan benar.

# Checklist

- [ ] Sudah menyelesaikan `15-challenge/easy` sebelum membuka `easy/` di sini.
- [ ] Sudah menyelesaikan `15-challenge/medium` sebelum membuka `medium/` di sini.
- [ ] Sudah menyelesaikan `15-challenge/hard` sebelum membuka `hard/` di sini.

# Hint

Jangan buka folder ini SEBELUM mencoba sendiri — kamu akan
kehilangan latihan berpikirnya. Fokus membandingkan STRUKTUR &
LOGIKA, bukan mencari kode yang sama persis.
